# Private Local CSV Samples

This folder is for temporary local testing of real client-provided bank CSVs.

Important:

- This folder must remain gitignored.
- Do not commit real CSVs.
- Do not copy real rows into source code, test files, logs, screenshots or PR descriptions.
- Convert parser learnings into safe synthetic or redacted fixtures.
- Delete private samples when no longer required unless the client explicitly asks to keep them locally.
