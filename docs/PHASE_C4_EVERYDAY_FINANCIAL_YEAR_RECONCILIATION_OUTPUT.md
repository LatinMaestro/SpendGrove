## Scope

One pure deterministic JSON serializer for aggregate everyday financial-year reconciliation evidence.

No database query, accepted-source ID list, API route, download response, UI, accountant-pack change, stored data, schema or migration is included.

## Contract

- versioned reconciliation contract;
- exact generation time and bounded Australian financial year;
- AUD and integer-cent declarations;
- source mode and verified owner scope;
- Money in, Money out, transfer, split and diagnostic counts;
- uncategorised, Category-row and analytical Loan counts;
- Money in and Money out integer-cent totals;
- explicit zero analytical Loan cashflow contribution;
- fixed neutral notices and disclaimer.

## Fail-closed validation

Rejects:

- unsupported report contract, version, currency or money representation;
- invalid generation time or FY outside 2001–2100;
- unsafe/negative counts or totals;
- impossible zero-count/non-zero-total pairs;
- transfer and counted-record mismatches;
- Category count/total mismatches;
- duplicate direction/Category identities;
- null Category identities carrying any label other than canonical `Uncategorised`;
- fabricated uncategorised counts;
- incomplete owner-scoped diagnostics;
- fabricated eligible-only exclusions;
- diagnostic source-count mismatches;
- non-zero analytical Loan cashflow contribution.

## Privacy

Output excludes Transaction/Category/source IDs, raw CSV, filenames, narration, merchant history, notes, banking/Loan identifiers, Property addresses, provider payloads, secrets and private audit metadata.

Canonical notices are generated by the serializer; supplied report notices are not copied.
