# UI Review Guide

This guide helps the client review SpendGrove like a client reviewing a professional Apple app developer.

## What the agent must provide

For each major user-facing screen or workflow, provide:

- iPhone-sized screenshot or working preview note;
- desktop/web screenshot if relevant;
- empty state if applicable;
- loading state if applicable;
- error/warning state if applicable;
- key confirmation dialogs if applicable;
- short UX rationale;
- accessibility notes;
- known limitations.

## What the client should review

### First impression

- Does the screen feel calm, simple and trustworthy?
- Does it feel like SpendGrove, not a generic finance app?
- Does it look suitable for a beginner budget user?

### Navigation

- Is the next action obvious?
- Are labels plain English?
- Is advanced functionality hidden unless needed?

### Visual hierarchy

- Is the main information easy to find?
- Are there too many buttons or competing actions?
- Are warnings noticeable without being alarming?

### Mobile usability

- Are touch targets large enough?
- Is the content clipped?
- Are cards too dense?
- Is import review usable without a spreadsheet layout?

### Privacy clarity

- Does the UI explain what is and is not stored?
- Does CSV import make review-before-commit clear?
- Are private field exclusions communicated clearly?

### Accessibility

- Is text readable?
- Is colour contrast strong?
- Does the screen rely only on colour to show status?

## Review outcomes

The client may respond with:

- Approved.
- Approved with minor changes.
- Changes requested.
- Rework direction.
- Defer item to backlog.

## Example feedback

Useful feedback examples:

- “Make the Import button more prominent.”
- “This screen feels too dense on mobile.”
- “Use more plain-English wording.”
- “Move privacy explanation higher.”
- “Make category cards larger.”
- “Show the duplicate warning more clearly.”

The agent must translate plain-English feedback into implementation changes and summarise the changes in the next review package.
